# Payment Guard — Pitch Deck

Pitch deck for **Payment Guard**, our UAE Hackathon 2026 entry (Challenge #29, Cyber Resilience for SMEs): stops invoice fraud and phishing before money moves.

- `payment-guard-pitch.pptx` / `.pdf` — the deck
- `slides.md` — slide text and speaker notes
- `slides/` — the slides' HTML sources
- `build-deck.js` + `deck.json` — builds the .pptx

The product itself lives in [hackasnapa](https://github.com/ahmezk11/hackasnapa).
